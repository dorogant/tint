# Third-party licences

Tint's own code is under the MIT licence (see [LICENSE](LICENSE)). The app links a Rust library, `floe_core`, built from the crates below. This file lists every crate in that library's dependency graph for the macOS build (aarch64-apple-darwin), including build-time crates. Crates are grouped by the licence Tint uses them under; where a crate offers a choice, the Declared licence column shows all of it.

The Swift app has no third-party package dependencies.

Generated by `scripts/third-party-licenses.sh` from `core/Cargo.lock`. Don't edit by hand; rerun the script after changing dependencies.
